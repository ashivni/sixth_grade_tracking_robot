# Sixth Grade Tracking Robot

A place to learn basic C++ and, later, build an Arduino tracking robot.

Start with [the C++ exercises](exercises/cpp_basics/README.md). There are four simple questions with starter files and separate solutions.

Then try [Arduino basics: blink an LED](exercises/arduino_basics/README.md).

## Repository layout

- `exercises/cpp_basics/starter/`: code to read or complete.
- `exercises/cpp_basics/solutions/`: completed examples for checking work.
- `exercises/arduino_basics/`: a board introduction and built-in LED blinking exercise.
- Arduino robot code will be added later.

This repository starts with only these new learning materials.
